- building a standalone app for testing
- Prepare for building: Generate the native Android and iOS directories using npx expo prebuild: npx expo prebuild
- Build the app locally: Use npx expo run:ios (for iOS) or npx expo run:android (for Android) to build and run the app locally
- Distribute your app: After building, you can either:
  - Distribute through app stores: Prepare your app for app store distribution using EAS Build and EAS Submit.
  - Internally distribute: Use EAS Build with internal distribution options like Ad Hoc or Enterprise.
  - Test on simulators/emulators: Build for and install on iOS simulators or Android emulators using EAS Build.
